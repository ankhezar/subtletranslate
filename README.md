# SubtleTranslate for macOS

Quiet, instant translation right where you select text — built natively for **Apple Silicon** (`macOS 26.0+`) with **Liquid Glass**, **100% private on-device TranslateGemma AI**, and optional **Google Gemini Flash-Lite** streaming.

## Highlights

- **Instant Contextual HUD (`⌥⌘T`, `⌘C+C`, Services & Safari Extension):** Translate selected text in any app without leaving your workflow or cluttering the Dock.
- **Smart Primary / Fallback Routing & Dual Output (`+ English`):** Sub-millisecond offline language identification routes automatically into your primary target language (or your fallback language when copying text already in your primary language), with optional simultaneous English output underneath.
- **100% Private Offline Packs or Free-Tier Gemini Cloud:** Download dedicated **Google TranslateGemma** offline packs (`~2.5 GB` Standard / `~7.3 GB` High Precision) for zero-internet translation across 55 languages (including Slovenian & Ukrainian), use built-in macOS Translation packs, or connect a Google AI Studio API key stored in macOS Keychain.
- **Featherweight Footprint:** `~11 MB` native Apple Silicon app, `0.0` idle CPU/energy impact, and automatic `120s` idle RAM eviction.
