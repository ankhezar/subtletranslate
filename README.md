# Subtle: Instant Translator for macOS

Quiet, instant translation right where you select text, built natively for **Apple Silicon** (`macOS 15.0+`) with **Liquid Glass**, **100% private on-device TranslateGemma AI**, built-in **macOS Translation**, and multi-provider **BYOK Cloud** failover.

## Highlights

- **Instant Contextual HUD (`⌥⌘T`, `⌘C+C`, Services & Safari/Chromium Extensions):** Translate selected text in any app without leaving your workflow or cluttering the Dock, plus tear-off pinning (`📌`) and Wide Composer (`⤢`).
- **Smart Primary / Fallback Routing & Dual Output (`+ English`):** Sub-millisecond offline language identification routes automatically into your primary target language (or your fallback language when text is already in your primary language), with optional simultaneous English output underneath.
- **Private On-Device AI or Multi-Provider BYOK Cloud:** Use built-in **macOS Translation** (`~70 MB` system packs), download dedicated **Google TranslateGemma** offline packs (`~2.5 GB` Standard / `~7.3 GB` High Precision) for zero-internet translation, or connect personal API keys (**Google Gemini**, **DeepL**, **Groq**, **Microsoft Translator**, **Mistral AI**, **OpenRouter**, **OpenAI / Custom API**) stored privately in macOS Keychain.
- **Featherweight Native Footprint:** `<= 18 MB` native Apple Silicon app, `0.0` idle CPU/energy impact, and automatic `120s` idle RAM eviction.
